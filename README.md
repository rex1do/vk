# VK Player

Простой десктопный плеер для музыки ВКонтакте: вошёл один раз — и слушаешь, без браузера.

- вход через официальное окно ВК (внутри программы), по логину/паролю или по токену;
  поддерживаются коды подтверждения (SMS, приложение) и капча;
- «Моя музыка», рекомендации, поиск, ваши плейлисты;
- пауза/перемотка/громкость, перемешивание, повтор списка или трека;
- значок в трее, медиаклавиши (когда окно активно), пробел — пауза, Ctrl+←/→ — треки, Ctrl+F — поиск;
- следующий трек подгружается заранее, прослушанное кэшируется (до 500 МБ).

## Как запустить (Windows)

**Вариант 1 — готовый exe.** Откройте вкладку *Actions* → последняя сборка *Build Windows* →
скачайте `VKPlayer-windows`, распакуйте и запустите `VKPlayer.exe`.
(Если поставить тег `v1.0.0`, архив появится и в *Releases*.)

**Вариант 2 — из исходников.** Установите [Python 3.10+](https://www.python.org/downloads/)
(галочка *Add python.exe to PATH*), затем дважды кликните `run.bat`.
Первый запуск поставит зависимости (пару минут), дальше открывается сразу.

Собрать exe самому: `build.bat` → `dist\VKPlayer\VKPlayer.exe`.

Linux/macOS: `pip install -r requirements.txt && python run.py`.

## Как это устроено

ВК закрыл аудио-API для сторонних приложений, поэтому вход идёт от имени
Kate Mobile / официального Android-клиента — так же, как у других неофициальных плееров.
Музыка приходит в виде HLS-потока (`index.m3u8`, часть кусочков зашифрована AES-128):
плеер скачивает кусочки, расшифровывает, склеивает и проигрывает через Qt Multimedia (FFmpeg).

| Файл | Что внутри |
| --- | --- |
| `vkplayer/vk.py` | авторизация и запросы к VK API |
| `vkplayer/stream.py` | загрузка и расшифровка HLS, кэш |
| `vkplayer/auth.py` | окно входа, 2FA, капча |
| `vkplayer/app.py` | главное окно и логика плеера |

## Важно

- Токен хранится локально в `%APPDATA%\VKPlayer\VK Player\session.json`. «Аккаунт → Выйти» удаляет его.
- Пароль никуда, кроме `oauth.vk.com`, не отправляется и не сохраняется.
- Это неофициальный клиент: ВК может в любой момент поменять что-то у себя, и вход/музыка перестанут работать.
