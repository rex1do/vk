# VK Player

Десктопный плеер для ВК Музыки в стиле «жидкого стекла»: размытый фон из обложки текущего
трека, стеклянные панели, своя нижняя панель плеера (обложка, ⏮ ⏯ ⏭, перемотка, громкость),
меню разделов и поиск. В центре — только музыкальный раздел ВК: без шапки, ленты, чатов,
меню соцсети и рекламы.

## Только плеер

Перейти из программы на другие страницы ВК (профили, сообщества, ленту, сообщения) нельзя:
такие ссылки не срабатывают, а если ВК сам уводит со страниц музыки — программа возвращает
в плеер. Разрешены только разделы музыки (треки, плейлисты, альбомы, артисты, поиск) и вход.

## Безопасно для аккаунта

Внутри — **официальный сайт** ВК, вход на официальной странице ВК. Никаких неофициальных API
и токенов чужих приложений (Kate Mobile и т.п.), за которые ВК в 2025–2026 годах замораживает
аккаунты. Для ВКонтакте VK Player выглядит как обычный браузер Chrome.

## Возможности

- разделы: «Главная», «Моя музыка», «Рекомендации», «Плейлисты», «Чарт», «Новинки», поиск;
- нижняя панель плеера: обложка, название, ⏮ ⏯ ⏭, перемотка, громкость;
- следующий трек включается сам, даже если окно свёрнуто;
- адаптивность: в узком окне меню сворачивается в иконки, панель плеера становится компактной,
  страница ВК плавно уменьшается;
- крестик сворачивает в трей — музыка играет дальше; в меню трея — пауза, переключение, выход
  из аккаунта и закрытие программы;
- медиаклавиши клавиатуры;
- горячие клавиши: `Ctrl+F` — поиск, `Ctrl+P` — играть/пауза, `Ctrl+M` — главная, `F5` — обновить,
  `Alt+←/→` — назад/вперёд, `Ctrl+W` — свернуть в трей, `Ctrl+Q` — выйти.

## Установка (Windows)

Вкладка *Actions* → последняя сборка *Build Windows* → артефакт `VKPlayer-windows`. Внутри:

- `VKPlayer-Setup-*.exe` — установщик (ярлык в меню «Пуск»);
- `VKPlayer-Portable-*.exe` — без установки, просто запустить.

## Сборка из исходников

```
npm install
npm start          # запустить
npm run dist       # собрать exe в dist/
```
