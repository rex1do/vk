# VK Player

Десктопный плеер для ВК Музыки: своя тёмная оболочка с боковой панелью (поиск, разделы,
«Сейчас играет» с обложкой и кнопками), справа — музыкальный раздел ВК без лишнего
(меню соцсети и реклама скрыты). Значок в трее, музыка играет в фоне, медиаклавиши.

## Почему так устроено

Внутри открывается **официальный сайт** `vk.com/audio`, вход — на официальной странице ВК.
Программа не использует неофициальные API и токены чужих приложений (Kate Mobile и т.п.):
в 2025–2026 годах ВК замораживает аккаунты за такие клиенты. Для ВКонтакте VK Player выглядит
как обычный браузер Chrome, поэтому риска блокировки нет.

## Возможности

- своя боковая панель: поиск, «Главная», «Моя музыка», «Рекомендации», «Плейлисты», «Чарт», «Новинки»;
- карточка «Сейчас играет» с обложкой и кнопками ⏮ ⏯ ⏭ (те же команды, что от медиаклавиш);
- тёмная тема, меню ВКонтакте и реклама скрыты — остаётся только музыка;
- вход сохраняется между запусками;
- крестик сворачивает в трей — музыка играет дальше; «Выход» — в меню значка в трее;
- медиаклавиши (⏯ ⏭ ⏮) и плашка громкости Windows управляют музыкой;
- в заголовке окна и подсказке трея — название текущего трека;
- ссылки на сторонние сайты открываются в обычном браузере;
- горячие клавиши: `Ctrl+M` — главная, `Ctrl+F` — поиск, `F5` — обновить, `Alt+←/→` — назад/вперёд,
  `Ctrl+=`/`Ctrl+-` — масштаб, `Ctrl+W` — свернуть в трей, `Ctrl+Q` — выйти.

## Установка (Windows)

Вкладка *Actions* → последняя сборка *Build Windows* → артефакт `VKPlayer-windows`. Внутри:

- `VKPlayer-Setup-*.exe` — установщик (ярлык в меню «Пуск»);
- `VKPlayer-Portable-*.exe` — без установки, просто запустить.

## Сборка из исходников

```
npm install
npm start          # запустить
npm run dist       # собрать exe в dist/
```
